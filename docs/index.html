FILE 01

The Question

Should a recommendation system optimize for simple interaction volume or for behavior that better represents meaningful engagement?

Can personalization improve the chance that the first recommendation shown to a user leads to meaningful engagement?

FILE 06

Experiment Plan

Offline ranking improvement is useful evidence, but it is not enough to launch a new policy. A/B testing is required because policies that seem effective often cause hidden harm or fail in real-world use.

50%

Control

Historical ranking

≈15K users user-level randomization
50%

Treatment

Personalized ranking

BASELINE RATE 8.42%

Current long-view rate used as the experiment starting point.

MINIMUM DETECTABLE EFFECT +5%

Smallest relative improvement the experiment is designed to detect.

STATISTICAL POWER 80%

Probability of detecting the target lift if it is truly present.

DESIGN EFFECT 4.62×

Sample-size adjustment to increase the number of users required because multiple interactions from the same user do not count as fully independent observations.

A/A VALIDATION PASSED

500 control users, 500 treatment users, SRM p = 1.00, primary metric p = 0.911.

CASE CONCLUSION

Use meaningful engagement as a ranking signal. Test personalization before launch.

Long-view behavior was a strong measure of engagement quality. The personalized ranking model improved offline recommendation quality, especially at the first ranked position.

The next product step would be a user-level online experiment with defined guardrails and monitoring.
