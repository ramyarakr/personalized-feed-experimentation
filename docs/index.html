Should a recommendation feed optimize clicks or meaningful engagement?

A product data science case study using real recommendation logs to connect user behavior, experimentation, causal measurement, and personalization to a launch decision.

Product question

Determine whether a meaningful-engagement ranking objective should replace a click-oriented objective and identify the right rollout population.

Dataset

KuaiRand recommendation logs with sequential behavior, rich feedback signals, and randomized exposure data.

Methods

SQL analytics, cohorts, experimentation, causal inference, statistical modeling, recommendation evaluation, and heterogeneous effects.

Decision

Analysis in progress. Final ship / iterate / reject recommendation will be published here.

Case study

  1. Define success. Build the metric tree and guardrails.
  2. Diagnose behavior. Find where engagement and repeat usage differ across users.
  3. Measure causally. Contrast biased observational behavior with randomized exposure evidence.
  4. Evaluate personalization. Test whether a meaningful-engagement objective improves product outcomes.
  5. Make the call. Recommend a launch strategy with uncertainty and tradeoffs.
