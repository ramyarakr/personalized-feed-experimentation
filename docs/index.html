CASE SUMMARY

Executive Summary

From behavioral data to a personalized ranking recommendation and experiment plan.

01 · Problem

What should a recommendation system optimize?

Tested whether meaningful engagement is a better ranking signal than simple interaction volume, and whether personalization improves which content is ranked first.

02 · Process
Audit Validated 11.7M+ events, schema, coverage, and metric definitions.
→
Analyze Built 147K+ sessions and studied engagement and retention.
→
Model Tested behavioral drivers and built personalized ranking.
→
Experiment Designed a user-level A/B test and production safeguards.
03 · Key Findings
ENGAGEMENT QUALITY 13.4×

higher comment rate on long-view interactions

NEGATIVE FEEDBACK −75%

lower hate rate on long-view interactions

PERSONALIZATION +5.9%

relative Precision@1 improvement

MODEL QUALITY 0.681

ROC-AUC vs 0.570 historical baseline

04 · Statistical Validation
Logistic Regression Tested whether long-view rate independently predicted next-day return.
Negative Binomial Regression Modeled future session counts after detecting strong count overdispersion.
Interaction + Within-User Tests Checked whether engagement effects differed across surfaces and users.
A/A Validation Verified experiment assignment and inference before treatment interpretation.
05 · Recommended A/B Test
Historical Ranking 50% Control
≈15K Users User-level randomization
Personalized Ranking 50% Treatment
Primary Metric Long-view rate
Target MDE +5% relative
Power 80%
Guardrail Hate rate

A/A validation passed with a 500/500 user split, SRM p = 1.00, and primary-metric p = 0.911. The design effect was used to adjust the sample requirement for repeated interactions from the same users.

CASE CONCLUSION

Optimize for meaningful engagement. Test personalization before launch.
